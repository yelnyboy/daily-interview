# 自我改进型智能体

**日期**: 2026-10-26 | **类型**: Theory | **原始分类**: Agent设计模式 | **路线图模块**: 04-Agent基础与架构原则 | **难度**: 高级 | **来源**: GitHub

## 解答

1. 核心概念：自我改进型智能体是一种能够根据过去的经验和环境反馈，自动调整自身行为、提示词或底层逻辑的智能体架构。2. 反思机制：通过引入自我反思步骤，智能体评估其先前动作的输出质量，识别错误或不足，生成改进建议。3. 记忆更新：将反思得到的经验教训存入长期记忆，在后续任务中检索这些经验以指导决策，避免重复犯错。4. 提示词优化：智能体可以自动重写或优化其系统提示词，以在特定任务上获得更好的表现。5. 追问点：如何避免智能体陷入局部最优或因错误反思而产生性能退化？

## 核心考点

- 自我反思
- 长期记忆
- 提示词优化
- 经验积累
- 反馈循环

## 常见追问

> 如何评估智能体的自我改进确实带来了正向收益而非过拟合？
