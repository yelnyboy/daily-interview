# Agent 12-Factor 第12条原则

**日期**: 2026-10-14 | **类型**: Theory | **原始分类**: Agent基础 | **路线图模块**: 04-Agent基础与架构原则 | **难度**: 中级 | **来源**: GitHub

## 解答

Agent 12-Factor 的第12条原则通常关注“管理任务”或“可观测性”。以管理任务为例，核心思想是将一次性管理任务作为独立进程运行。具体包括以下几点：
1. 进程隔离：数据迁移、状态清理或模型微调等管理任务应作为一次性进程运行，与常驻的 Agent 主服务隔离，避免影响主服务的稳定性。
2. 环境一致：管理任务必须在与主应用完全相同的环境中执行，使用相同的代码库和依赖版本，确保操作结果的一致性。
3. 无状态执行：一次性进程不应依赖内存状态，所有必要数据需从外部数据库或状态存储中获取，执行结果也应持久化到外部存储。
4. 日志与审计：管理任务的执行过程需输出详细日志，便于事后审计和故障排查，日志格式应与主服务保持一致。
常见追问点：如何保证管理任务在执行失败时能够安全重试？

## 核心考点

- 进程隔离
- 环境一致性
- 无状态执行
- 日志审计
