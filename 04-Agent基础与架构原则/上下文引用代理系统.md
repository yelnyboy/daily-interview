# 上下文引用代理系统

**日期**: 2026-10-28 | **类型**: Theory | **原始分类**: Agent设计模式 | **路线图模块**: 04-Agent基础与架构原则 | **难度**: 中级 | **来源**: GitHub

## 解答

上下文引用代理系统是一种Agent设计模式，旨在解决长上下文或复杂对话中信息丢失和幻觉问题。
1. 核心概念：Agent在生成回复时，不仅输出答案，还显式标注答案所依赖的上下文片段或来源索引。
2. 实现机制：通常结合RAG技术，将长文档分块并建立索引。Agent在推理时检索相关块，并在最终输出中附带这些块的引用标记。
3. 核心优势：增强了模型输出的可解释性和可追溯性，显著降低了幻觉风险，便于人工审核与验证。
4. 应用场景：广泛应用于法律合同审查、医疗病历分析、长代码库理解等对事实准确性要求极高的领域。
常见追问点：如何平衡引用粒度与上下文窗口限制？如何评估引用的准确性与召回率？
