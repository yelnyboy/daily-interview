# 分布式系统面试连环炮

**日期**: 2026-10-12 | **类型**: Theory | **分类**: 分布式 | **难度**: 中级 | **来源**: GitHub

## 解答

分布式系统面试连环炮通常考察候选人对分布式基础理论的系统性理解。第一，CAP定理是核心，分布式系统在一致性、可用性和分区容错性中只能满足其中两个，通常P是必选项，需在C和A间权衡。第二，BASE理论是CAP的妥协，即基本可用、软状态和最终一致性，是大规模互联网系统的实践指南。第三，分布式锁是常考点，需保证互斥性和可重入性，常见实现有Redis（RedLock算法）和Zookeeper（临时顺序节点）。第四，分布式事务解决数据一致性问题，常见方案包括两阶段提交（2PC）、TCC补偿型、本地消息表和Saga事务。第五，限流与熔断保障高可用，常见算法有令牌桶和漏桶，熔断可参考Sentinel或Hystrix的断路器模式。

## 核心考点

- CAP定理
- BASE理论
- 分布式锁
- 分布式事务
- 高可用保障
