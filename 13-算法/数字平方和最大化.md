# 数字平方和最大化

**日期**: 2026-10-14 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 中级 | **来源**: LeetCode

**Tags**: 贪心, 数学

## 解答

思路：题目要求将一个数字字符串分割成两部分，使得这两部分对应的整数的平方和最大。我们可以采用贪心策略，遍历所有可能的分割点，计算左右两部分整数的平方和，并记录最大值。由于数字长度通常有限，这种暴力遍历的时间复杂度为 O(n)，其中 n 为字符串长度，非常高效。需要注意的是，分割后的两部分不能有前导零（除非本身就是0），但在计算平方和时，前导零会被自动忽略（如 '01' 会被解析为 1）。代码框架（Python）：

def maximizeSumOfSquares(num: str) -> int:
    max_sum = 0
    for i in range(1, len(num)):
        left = int(num[:i])
        right = int(num[i:])
        current_sum = left * left + right * right
        max_sum = max(max_sum, current_sum)
    return max_sum

常见追问点：如果题目允许分割成 k 个部分该如何处理？此时可以使用动态规划，定义 dp[i][j] 为前 i 个字符分割成 j 部分的最大平方和。
