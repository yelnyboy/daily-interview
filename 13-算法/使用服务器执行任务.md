# 使用服务器执行任务

**日期**: 2026-11-07 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 中级 | **来源**: LeetCode

**Tags**: 数组, 堆（优先队列）

## 解答

思路：本题是典型的双堆（优先队列）模拟题。维护两个堆：1) 空闲堆 free，按 (权重, 下标) 排序，存放当前可用的服务器；2) 工作堆 busy，按 (结束时间, 权重, 下标) 排序，存放正在运行的服务器。遍历每个任务 i（到达时间为 i），先从 busy 堆中把结束时间 <= i 的服务器弹出并放回 free 堆；若 free 堆非空，弹出最优服务器执行该任务，其结束时间为 i + tasks[i]，压入 busy 堆；若 free 为空，则任务需等待，取 busy 堆堆顶的最早结束时间 t，将所有结束时间 <= t 的服务器释放后再分配。记录每个任务分配的服务器下标即可。时间复杂度 O((n+m)logm)，n 为任务数，m 为服务器数。代码框架（Python）：
import heapq
def assignTasks(servers, tasks):
    free = [(w, i) for i, w in enumerate(servers)]
    heapq.heapify(free)
    busy = []  # (结束时间, 权重, 下标)
    ans = []
    for i, t in enumerate(tasks):
        while busy and busy[0][0] <= i:
            _, w, idx = heapq.heappop(busy)
            heapq.heappush(free, (w, idx))
        if free:
            w, idx = heapq.heappop(free)
            heapq.heappush(busy, (i + t, w, idx))
        else:
            time = busy[0][0]
            while busy and busy[0][0] <= time:
                _, w, idx = heapq.heappop(busy)
                heapq.heappush(free, (w, idx))
            w, idx = heapq.heappop(free)
            heapq.heappush(busy, (time + t, w, idx))
        ans.append(idx)
    return ans
