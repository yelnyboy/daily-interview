# 字符串数字求和

**日期**: 2026-11-16 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 初级 | **来源**: LeetCode

**Tags**: 字符串, 模拟

## 解答

思路：这是一道简单模拟题。给定一个字符串s和整数k，需要反复将s分成每段长度为k的连续子串，将每段中数字求和后拼接，直到字符串长度不超过k为止。实现步骤：1) 当len(s) > k时进入循环；2) 按步长k切分字符串；3) 对每个片段求各位数字之和并转为字符串拼接；4) 循环结束返回s。注意用切片s[i:i+k]处理最后不足k的片段，Python切片自动处理越界。代码框架（Python）：

def digitSum(s, k):
    while len(s) > k:
        parts = []
        for i in range(0, len(s), k):
            seg = s[i:i+k]
            parts.append(str(sum(int(c) for c in seg)))
        s = ''.join(parts)
    return s

时间复杂度：每轮字符串长度约缩小k倍，总复杂度约O(n)，空间O(n)。常见追问：如何证明循环一定会终止（每轮长度至少缩小为原来的1/k）；能否用递归实现；边界情况如初始长度已小于等于k时直接返回原串。
