# 对数组执行操作以最大化平方和

**日期**: 2026-10-12 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 高级 | **来源**: LeetCode

**Tags**: 贪心, 位运算, 数组, 哈希表

## 解答

思路：题目允许对数组中任意两个元素执行任意次操作：`a, b = a & b, a | b`。观察发现，对于任意一个二进制位，操作前后该位上1的总数保持不变。因此，该操作的本质是允许我们将数组中所有1的二进制位重新分配到任意位置。为了使选取的k个元素的平方和最大，由于平方函数是凸函数，应尽量让某些元素的值尽可能大。因此采用贪心策略：统计所有元素在每个二进制位上1的总数，然后从最高位到最低位构建k个元素，每次将剩余的1尽可能分配给当前构建的元素。代码框架(Python)：
```python
def maxSum(nums, k):
    cnt = [0] * 31
    for x in nums:
        for i in range(31):
            if (x >> i) & 1:
                cnt[i] += 1
    ans = 0
    mod = 10**9 + 7
    for _ in range(k):
        cur = 0
        for i in range(31):
            if cnt[i] > 0:
                cnt[i] -= 1
                cur |= (1 << i)
        ans = (ans + cur * cur) % mod
    return ans
```
