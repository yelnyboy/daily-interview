# 查找两个数组间的距离值

**日期**: 2026-11-05 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 初级 | **来源**: LeetCode

**Tags**: 数组, 双指针, 二分查找, 排序

## 解答

题目要求：给定数组 arr1 和 arr2 以及整数 d，返回 arr1 中满足「对 arr2 中所有元素 y，都有 |x - y| > d」的元素 x 的数量。

思路一（暴力）：对 arr1 每个元素 x，遍历 arr2 检查是否存在 |x - y| <= d，时间复杂度 O(n*m)。

思路二（排序 + 二分查找，推荐）：先对 arr2 排序，对每个 x 在 arr2 中二分查找第一个 >= x 的位置，只需检查该位置及其前一个位置的元素与 x 的差值是否 <= d。若最近的两个候选都不满足，则 x 是合法的。时间复杂度 O((n+m) log m)。

思路三（排序 + 双指针）：两个数组都排序后，用指针同步推进判断。

代码框架（Python）：
```python
def findTheDistanceValue(arr1, arr2, d):
    import bisect
    arr2.sort()
    count = 0
    for x in arr1:
        i = bisect.bisect_left(arr2, x)
        if (i < len(arr2) and abs(arr2[i] - x) <= d) or \
           (i > 0 and abs(x - arr2[i-1]) <= d):
            continue
        count += 1
    return count
```

常见追问：为什么只需检查二分位置的前后两个元素？因为排序后与 x 距离最近的元素必然在插入点两侧。还可能追问时间复杂度分析、bisect_left 与 bisect_right 的区别。
