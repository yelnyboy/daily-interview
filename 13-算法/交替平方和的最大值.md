# 交替平方和的最大值

**日期**: 2026-10-13 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 中级 | **来源**: LeetCode

**Tags**: 贪心, 数组, 排序

## 解答

思路：题目要求从数组中选取元素，使得其平方的交替和（如 a1^2 - a2^2 + a3^2 - ...）最大。由于平方操作不改变非负数的大小关系，我们可以先对原数组进行降序排序。为了使交替和最大，我们应当将最大的数放在正号位置，次大的数放在负号位置，第三大的数放在正号位置，以此类推。这实际上是一个贪心算法的过程，每次选择当前能提供最大收益的元素。

代码框架（Python）：
def max_alternating_sum(nums):
    nums.sort(reverse=True)
    res = 0
    sign = 1
    for num in nums:
        res += sign * (num * num)
        sign *= -1
    return res

常见追问点：如果数组中存在负数，上述贪心策略是否依然适用？由于负数平方后可能变为最大值，排序时直接按原数值排序会导致负数排在后面，但实际上其平方可能很大，因此排序策略需要改为按绝对值降序排序。
