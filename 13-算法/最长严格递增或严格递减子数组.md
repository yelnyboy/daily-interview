# 最长严格递增或严格递减子数组

**日期**: 2026-11-12 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 初级 | **来源**: LeetCode

**Tags**: 数组

## 解答

思路：这是一道典型的线性扫描题。用两个变量 inc 和 dec 分别记录以当前元素结尾的最长严格递增子数组长度和最长严格递减子数组长度。遍历数组时：若 nums[i] > nums[i-1]，则 inc = inc + 1，否则 inc 重置为 1；同理若 nums[i] < nums[i-1]，dec = dec + 1，否则重置为 1。注意相等元素会使两者都重置为 1。每一步用 max(inc, dec) 更新答案。时间复杂度 O(n)，空间复杂度 O(1)。代码框架（Python）：

def longestMonotonicSubarray(nums):
    inc = dec = ans = 1
    for i in range(1, len(nums)):
        if nums[i] > nums[i-1]:
            inc, dec = inc + 1, 1
        elif nums[i] < nums[i-1]:
            dec, inc = dec + 1, 1
        else:
            inc = dec = 1
        ans = max(ans, inc, dec)
    return ans

常见追问点：1) 如何处理空数组或单元素数组（返回 1 或 0，需与面试官确认边界）；2) 如果要求的是子序列而非子数组，如何用动态规划或贪心+二分（O(n log n) 的最长上升子序列 LIS）解决；3) 能否只用一次遍历且常数空间（本题已满足）。
