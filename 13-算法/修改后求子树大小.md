# 修改后求子树大小

**日期**: 2026-11-21 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 中级 | **来源**: LeetCode

**Tags**: 树, 深度优先搜索, 数组, 哈希表, 字符串

## 解答

思路：题目给定一棵以节点0为根的树，每个节点可以重新指定父节点（改为最近的、拥有相同字符号的祖先），求最终每个节点为根的子树大小。

分两步解决：
1. 第一次DFS：对每个节点找到与其字符相同的最近真祖先，更新parent数组。可以用一个栈/数组维护"从根到当前节点路径上每种字符最近出现的节点"，进入节点时保存旧值、设置新值，回溯时恢复旧值。
2. 第二次DFS：按新的parent数组统计子树大小。可以按逆拓扑序（节点编号从大到小，因为parent[i] < i）累加：size[i]初始为1，然后从大到小遍历，size[parent[i]] += size[i]。

代码框架（Python）：
```python
def findSubtreeSizes(self, parent, s):
    n = len(parent)
    # 步骤1：重定向父节点
    adj = [[] for _ in range(n)]
    for i in range(1, n):
        adj[parent[i]].append(i)
    last = [-1] * 26  # 每种字符最近的祖先
    def dfs(u):
        c = ord(s[u]) - ord('a')
        old = last[c]
        if last[c] != -1:
            parent[u] = last[c]
        last[c] = u
        for v in adj[u]:
            dfs(v)
        last[c] = old  # 回溯恢复
    dfs(0)
    # 步骤2：统计子树大小
    size = [1] * n
    for i in range(n - 1, 0, -1):
        size[parent[i]] += size[i]
    return size
```

常见追问点：为什么回溯时要恢复旧值（保证只考虑真祖先）；时间复杂度O(n)；能否用迭代DFS避免递归栈溢出。
