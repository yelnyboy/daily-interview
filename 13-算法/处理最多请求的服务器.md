# 处理最多请求的服务器

**日期**: 2026-11-09 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 高级 | **来源**: LeetCode

**Tags**: 数组, 有序集合, 模拟, 堆（优先队列）

## 解答

思路：有 k 台服务器按 0~k-1 编号，第 i 个请求在 arrival[i] 时刻到达，占用服务器 load 时间。分配规则：优先选空闲且编号最小的服务器；若无空闲服务器则丢弃请求。核心是维护两个数据结构：1) 空闲服务器集合，需要支持「找 ≥ 某编号的最小元素，否则回绕到全局最小」，用有序集合（SortedList / TreeSet）；2) 忙碌服务器，需要按结束时间取出，用最小堆存 (结束时间, 服务器编号)。每个请求到达时，先把堆中结束时间 ≤ 当前时间的服务器弹回空闲集合；然后查找空闲集合中 ≥ i % k 的最小服务器，找不到则取集合最小值（回绕）；分配后从空闲集合删除，压入堆 (arrival + load, server)。最后统计每台服务器处理次数，取最大值对应的所有服务器。时间复杂度 O(n log k)。代码框架（Python）：

from sortedcontainers import SortedList
import heapq

def busiestServers(k, arrival, load):
    free = SortedList(range(k))
    busy = []  # (end_time, server_id)
    count = [0] * k
    for i, (a, l) in enumerate(zip(arrival, load)):
        while busy and busy[0][0] <= a:
            free.add(heapq.heappop(busy)[1])
        if not free:
            continue
        idx = free.bisect_left(i % k)
        if idx == len(free):
            idx = 0
        s = free.pop(idx)
        count[s] += 1
        heapq.heappush(busy, (a + l, s))
    m = max(count)
    return [i for i, c in enumerate(count) if c == m]

## 核心考点

- 有序集合（TreeSet/SortedList）
- 最小堆（优先队列）
- 回绕查找 bisect_left
- 模拟与贪心分配
- 时间复杂度 O(n log k)
