# 统计共同度过的时间

**日期**: 2026-10-24 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 初级 | **来源**: LeetCode

**Tags**: 数学, 字符串

## 解答

思路：将给定的日期字符串转换为一年中的第几天，然后求两个时间区间的交集长度。首先构建一个数组记录平年每个月的天数，并计算前缀和以便快速转换日期。然后分别计算Alice和Bob到达和离开日期对应的天数。两人共同度过的时间即为两个区间 [arriveAlice, leaveAlice] 和 [arriveBob, leaveBob] 的交集。交集的左边界为两人到达日期的最大值，右边界为两人离开日期的最小值。如果左边界小于等于右边界，则共同度过的天数为 右边界 - 左边界 + 1，否则为0。代码框架（Python）：

def countDaysTogether(arriveAlice, leaveAlice, arriveBob, leaveBob):
    days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
    def get_day(date_str):
        m, d = map(int, date_str.split('-'))
        return sum(days[:m-1]) + d
    a_arr, a_lea = get_day(arriveAlice), get_day(leaveAlice)
    b_arr, b_lea = get_day(arriveBob), get_day(leaveBob)
    start = max(a_arr, b_arr)
    end = min(a_lea, b_lea)
    return max(0, end - start + 1)
