# 排序数组中查找目标索引

**日期**: 2026-10-19 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 初级 | **来源**: LeetCode

**Tags**: 数组, 二分查找, 排序

## 解答

思路：先对数组进行非递减排序，然后遍历数组收集等于目标值的元素索引。也可优化为先排序，再用二分查找定位目标值的左右边界，返回该区间内的所有索引。

代码框架（Python）：
```python
class Solution:
    def targetIndices(self, nums: List[int], target: int) -> List[int]:
        nums.sort()
        res = []
        for i, num in enumerate(nums):
            if num == target:
                res.append(i)
        return res
```

二分查找优化版本：找到第一个大于等于target的位置left，第一个大于target的位置right，返回range(left, right)。
