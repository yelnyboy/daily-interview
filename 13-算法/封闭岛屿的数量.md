# 封闭岛屿的数量

**日期**: 2026-10-25 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 中级 | **来源**: LeetCode

**Tags**: 深度优先搜索, 广度优先搜索, 并查集, 数组, 矩阵

## 解答

思路：封闭岛屿是指完全被水（1）包围的陆地（0），且不接触矩阵边界。因此，解决此题的关键是先排除与边界相连的陆地。
1. 遍历矩阵的四个边界，如果遇到0，则从该点启动深度优先搜索（DFS），将所有相连的0标记为1（或已访问状态），因为这些陆地不是封闭岛屿。
2. 边界处理完成后，再次遍历内部矩阵。此时剩下的0必定属于封闭岛屿。
3. 遇到0时，封闭岛屿数量加1，并通过DFS将其连通的所有0标记为已访问，避免重复计算。
代码框架（Python）：
def closedIsland(grid):
    m, n = len(grid), len(grid[0])
    def dfs(i, j):
        if 0 <= i < m and 0 <= j < n and grid[i][j] == 0:
            grid[i][j] = 1
            dfs(i+1, j)
            dfs(i-1, j)
            dfs(i, j+1)
            dfs(i, j-1)
    for i in range(m):
        for j in [0, n-1]:
            dfs(i, j)
    for j in range(n):
        for i in [0, m-1]:
            dfs(i, j)
    count = 0
    for i in range(1, m-1):
        for j in range(1, n-1):
            if grid[i][j] == 0:
                count += 1
                dfs(i, j)
    return count
