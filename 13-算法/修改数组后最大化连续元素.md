# 修改数组后最大化连续元素

**日期**: 2026-11-20 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 高级 | **来源**: LeetCode

**Tags**: 数组, 动态规划, 排序

## 解答

思路：将数组每个元素 x 拆成两个候选值 (x-1, x+1)，问题转化为：从 2n 个候选值中选出一个子集，使得排序后相邻差值恰好为 1，求最长连续序列长度。这是经典的「最长连续递增子序列」变形（类似 LeetCode 2407 的简化版）。

步骤：
1. 收集所有候选值 (x-1, x+1)，去重后排序；
2. 动态规划：dp[v] 表示以值 v 结尾的最长连续序列长度；
3. 遍历排序后的候选值 v，转移方程 dp[v] = dp[v-1] + 1（若 v-1 存在于候选集中）；
4. 答案为 max(dp[v])。

由于候选值排序后单调，可用哈希表存 dp 值，转移 O(1)，总复杂度 O(n log n)。

代码框架：
```python
def maxConsecutive(nums):
    candidates = sorted({v for x in nums for v in (x-1, x+1)})
    dp = {}
    best = 0
    for v in candidates:
        dp[v] = dp.get(v-1, 0) + 1
        best = max(best, dp[v])
    return best
```

常见追问：为什么每个元素只考虑 x-1 和 x+1？因为修改后必须与原值差 1，且每个元素只能改一次；若允许不改，可加入 x 本身作为候选。还可追问如何输出具体方案（记录 dp 前驱）。

## 核心考点

- 动态规划
- 排序去重
- 值域哈希转移
- 候选值拆分
- O(n log n) 复杂度分析
