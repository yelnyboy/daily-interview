# 爬楼梯 II

**日期**: 2026-11-10 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 中级 | **来源**: LeetCode

## 解答

思路：这是经典爬楼梯问题的变体。假设每次可以爬 1 或 2 个台阶，问到达第 n 阶有多少种方法。本质是斐波那契数列：dp[i] = dp[i-1] + dp[i-2]，因为到达第 i 阶只能从第 i-1 阶（爬1步）或第 i-2 阶（爬2步）转移而来。若变体允许爬 1~k 步，则 dp[i] = sum(dp[i-j]) for j in 1..k，可用滑动窗口优化到 O(n*k) 或 O(n)。基础版本可用滚动变量将空间优化到 O(1)。代码框架（Python）：

def climb_stairs(n):
    if n <= 2:
        return n
    a, b = 1, 2
    for _ in range(3, n + 1):
        a, b = b, a + b
    return b

常见追问点：1) 时间复杂度 O(n)、空间复杂度 O(1)；2) 能否用矩阵快速幂优化到 O(log n)；3) 若台阶带费用（最小花费爬楼梯）如何变形；4) 若步长集合为任意集合如何处理；5) 结果可能溢出时如何取模。

## 核心考点

- 动态规划
- 斐波那契数列
- 滚动变量空间优化
- 状态转移方程
- 矩阵快速幂优化
