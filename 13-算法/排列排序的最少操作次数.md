# 排列排序的最少操作次数

**日期**: 2026-10-22 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 中级 | **来源**: LeetCode

**Tags**: 数组

## 解答

思路：将排列视为一个图，每个元素指向它最终排序后应在的位置。这样图会被分解为若干个环。要将排列排序，对于每个长度为 k 的环，最少需要 k-1 次交换操作。因此，总的最少交换次数为 n - cycles，其中 n 是元素个数，cycles 是环的数量。
代码框架（Python）：
```python
def min_operations_to_sort(arr):
    n = len(arr)
    visited = [False] * n
    operations = 0
    for i in range(n):
        if not visited[i]:
            cycle_size = 0
            j = i
            while not visited[j]:
                visited[j] = True
                j = arr[j] - 1
                cycle_size += 1
            if cycle_size > 1:
                operations += cycle_size - 1
    return operations
```
常见追问点：如果每次只能交换相邻元素，最少操作次数是多少？（答：逆序对数）
