# 最小唯一子数组

**日期**: 2026-11-25 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 高级 | **来源**: LeetCode

**Tags**: 数组, 哈希表, 二分查找, 后缀数组, 哈希函数

## 解答

思路：题目要求在数组中找到所有元素互不相同（唯一）的最短子数组。核心方法是滑动窗口 + 哈希表：右指针扩张窗口，遇到重复元素时收缩左边界直到窗口内无重复，记录满足条件的最小窗口长度。若题目变体要求'恰好出现一次的最短子数组'或与后缀数组/滚动哈希结合（如求字典序最小的唯一子串），则需先预处理每个位置下一次出现的位置 next[i]，判断窗口内元素是否唯一。滚动哈希可用于快速比较子串是否重复出现，将比较代价降为 O(1)。代码框架：

def smallest_unique_subarray(arr):
    from collections import defaultdict
    cnt = defaultdict(int)
    left = 0
    ans = len(arr)
    for right, x in enumerate(arr):
        cnt[x] += 1
        while cnt[x] > 1:
            cnt[arr[left]] -= 1
            left += 1
        ans = min(ans, right - left + 1)
    return ans

时间复杂度 O(n)，空间 O(n)。常见追问：如何处理'所有元素都唯一'的边界情况；如果要求子数组长度至少为 k 怎么改；滚动哈希如何避免哈希冲突（可用双哈希）。面试中应先与面试官确认'唯一'的定义（元素互不相同 vs 子数组本身在原数组中只出现一次），后者需要后缀数组或后缀自动机求 LCP。
