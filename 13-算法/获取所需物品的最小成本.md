# 获取所需物品的最小成本

**日期**: 2026-11-11 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 中级 | **来源**: LeetCode

**Tags**: 贪心, 数学

## 解答

思路：本题属于典型的贪心+数学问题。核心观察是：如果每个物品只能单独购买，且需要获取指定的物品集合，那么总成本就是各物品价格之和，问题退化为简单求和；但如果存在'打包/替代'机制（如购买一个物品可顺带获得若干其他物品），则需要在多种获取方式之间做最优选择。贪心策略：1. 将每种获取方式的'单位收益'量化（如打包价格摊到物品数上的均价）；2. 按性价比排序，优先选择性价比最高的方式；3. 用数学推导证明贪心的正确性（交换论证：若最优解中存在可被更优方式替换的选择，交换后总成本不增）。代码框架（Python）：

def min_cost(costs, required):
    # costs: 每个物品单独价格; required: 需要的物品集合
    # 若存在套餐 offers: [(price, items_set), ...]
    import heapq
    total = 0
    remaining = set(required)
    # 按单位成本排序套餐
    offers.sort(key=lambda o: o[0] / len(o[1]))
    for price, items in offers:
        gain = remaining & set(items)
        if gain and price < sum(costs[i] for i in gain):
            total += price
            remaining -= gain
    total += sum(costs[i] for i in remaining)
    return total

常见追问点：贪心策略为何正确（交换论证/排序不等式）；何时贪心失效需要DP；边界情况（空需求、套餐覆盖全部物品）。
