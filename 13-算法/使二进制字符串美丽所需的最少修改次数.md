# 使二进制字符串美丽所需的最少修改次数

**日期**: 2026-11-18 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 中级 | **来源**: LeetCode

**Tags**: 字符串

## 解答

思路：题目要求将01串分割成若干长度为偶数的子串，每个子串内所有字符相同，求最少修改次数。关键观察：由于每个子串长度为偶数，最优分割方式就是每2个字符一组，即s[0..1], s[2..3], ...。因为任何更长的合法子串（如长度4）都可以拆成两个长度2的子串且代价不变，所以只需逐对检查。对每一对(s[i], s[i+1])，若两字符不同，则需要修改其中一个，代价+1；若相同，代价为0。累加即为答案。时间复杂度O(n)，空间O(1)。

代码框架：
```python
class Solution:
    def minChanges(self, s: str) -> int:
        ans = 0
        for i in range(0, len(s), 2):
            if s[i] != s[i + 1]:
                ans += 1
        return ans
```

常见追问点：1) 为什么按长度2分组是最优的？可证明更长的同字符偶数段拆分后代价不增；2) 若允许子串长度为任意>=2的偶数，答案是否变化？不变；3) 若要求子串长度为奇数或任意正整数，如何处理？需用DP求解。
