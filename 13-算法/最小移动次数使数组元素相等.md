# 最小移动次数使数组元素相等

**日期**: 2026-11-01 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 中级 | **来源**: LeetCode

**Tags**: 数组, 数学

## 解答

思路：题目要求每次让n-1个元素加1，这在数学上等价于让1个元素减1。为了让所有元素相等，最终所有元素都会等于数组中的最小值。因此，只需要计算每个元素与最小值的差值之和，即为最少移动次数。
代码框架（Python）：
def minMoves(nums):
    min_val = min(nums)
    return sum(num - min_val for num in nums)
常见追问点：时间复杂度为O(n)，空间复杂度为O(1)。如果数组很大导致结果溢出怎么办？Python中整数不会溢出，但在Java或C++中需使用long类型防止溢出。另外，如果要求输出最终的相等元素值，该值即为数组的最小值。

## 核心考点

- 数学转化
- 等价思维
- 差值求和
- 时间复杂度O(n)
