# 扭曲镜像路径计数

**日期**: 2026-10-31 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 中级 | **来源**: LeetCode

**Tags**: 数组, 动态规划, 矩阵

## 解答

思路：本题是在矩阵中计算满足镜像对称约束的路径数，属于动态规划问题。定义 dp[i][j] 表示从起点 (0,0) 到 (i,j) 的合法路径数，状态转移为 dp[i][j] = dp[i-1][j] + dp[i][j-1]。关键在于镜像约束：路径上每个格子的值需与其关于矩阵中心的镜像位置值一致，不一致则该位置路径数为0。

代码框架（Python）：
def twistedMirrorPathCount(grid):
    m, n = len(grid), len(grid[0])
    dp = [[0]*n for _ in range(m)]
    dp[0][0] = 1
    for i in range(m):
        for j in range(n):
            if i == 0 and j == 0:
                continue
            mi, mj = m-1-i, n-1-j
            if grid[i][j] != grid[mi][mj]:
                dp[i][j] = 0
                continue
            if i > 0:
                dp[i][j] += dp[i-1][j]
            if j > 0:
                dp[i][j] += dp[i][j-1]
    return dp[m-1][n-1]
