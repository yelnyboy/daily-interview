# 最小正和子数组

**日期**: 2026-11-14 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 中级 | **来源**: LeetCode

**Tags**: 数组, 前缀和, 滑动窗口

## 解答

题目要求在数组中找出和为正数且不小于某个给定值k的最短子数组，返回其长度，不存在则返回-1。思路：由于数组元素可能为负数，不能直接用普通滑动窗口（负数破坏单调性），应使用前缀和+单调队列（或有序集合）的方法。定义prefix[i]为前i项和，问题转化为：找最小的j-i使得prefix[j]-prefix[i] >= k且和为正。维护一个存储下标的单调递增队列：遍历j时，若队首下标i满足prefix[j]-prefix[i] >= k，则更新答案并弹出队首（因为j越大后续窗口只会更长，弹出不影响最优解）；同时从队尾弹出所有prefix值大于等于prefix[j]的下标，保持队列单调递增。时间复杂度O(n)。若题目限定元素全为正数，则可用简单滑动窗口：右指针扩张累加，和>=k时左指针收缩并记录最短长度。

代码框架（Python）：
from collections import deque
def shortestSubarray(nums, k):
    n = len(nums)
    prefix = [0]*(n+1)
    for i in range(n):
        prefix[i+1] = prefix[i] + nums[i]
    q = deque()
    ans = n+1
    for j in range(n+1):
        while q and prefix[j] - prefix[q[0]] >= k:
            ans = min(ans, j - q.popleft())
        while q and prefix[q[-1]] >= prefix[j]:
            q.pop()
        q.append(j)
    return ans if ans <= n else -1
