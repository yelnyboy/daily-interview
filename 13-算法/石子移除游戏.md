# 石子移除游戏

**日期**: 2026-11-26 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 初级 | **来源**: LeetCode

**Tags**: 数学, 模拟

## 解答

思路：这是典型的博弈模拟题。Alice 和 Bob 轮流从一堆共 n 个石子中取石子，每次取 1 到 10 个（不足 10 个则全取），取走最后一颗石子的玩家获胜，Alice 先手。由于 n ≤ 50，直接贪心模拟即可：每个玩家每轮都取当前能取的最大数量（即 min(10, 剩余)），这样总轮数最少，统计总轮数的奇偶性即可判断胜负——若总轮数为奇数，则 Alice 取走了最后一颗石子获胜，否则 Bob 获胜。代码框架：

def canAliceWin(n: int) -> bool:
    turn = 0  # 0 表示 Alice
    while n > 0:
        n -= min(10, n)
        turn ^= 1
    return turn == 1  # 最后一次取的是 Alice

常见追问点：1) 为什么贪心取 10 是正确的？因为取更多不会让当前玩家更差（对称性/单调性论证）；2) 若每次可取 1~k 个，本质是 Nim 类问题，可用模 (k+1) 的数学结论 O(1) 判断；3) 若规则改为取最后一颗者输，结论如何变化；4) 时间复杂度 O(n/10)，空间 O(1)。
