# 按数字和排序的最小交换次数

**日期**: 2026-10-17 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 中级 | **来源**: LeetCode

**Tags**: 数组, 哈希表, 排序

## 解答

思路：首先计算每个数字的数位和，然后我们需要将原数组按照数位和进行排序（如果数位和相同，则按数字本身大小排序）。求最小交换次数可以转化为求环的个数问题。我们将原数组和目标数组进行映射，通过并查集或访问数组找出有多少个环。最小交换次数 = 数组长度 - 环的个数。
代码框架（Python）：
def min_swaps(nums):
    def digit_sum(n):
        return sum(int(d) for d in str(n))
    n = len(nums)
    arr = [(digit_sum(num), num, i) for i, num in enumerate(nums)]
    arr.sort(key=lambda x: (x[0], x[1]))
    visited = [False] * n
    swaps = 0
    for i in range(n):
        if visited[i] or arr[i][2] == i:
            continue
        cycle_size = 0
        j = i
        while not visited[j]:
            visited[j] = True
            j = arr[j][2]
            cycle_size += 1
        if cycle_size > 1:
            swaps += cycle_size - 1
    return swaps
