# 网格中的最小异或路径

**日期**: 2026-10-28 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 中级 | **来源**: LeetCode

**Tags**: 位运算, 数组, 动态规划, 矩阵

## 解答

思路：由于异或操作不满足单调性，传统的动态规划无法通过比较前驱节点的最小异或和来推导当前节点的最优解。因此，我们需要记录到达每个格子所有可能的异或和。可以通过动态规划结合集合来实现。定义dp[i][j]为到达坐标(i, j)的所有可能异或和的集合。初始化dp[0][0] = {grid[0][0]}。对于网格中的每个位置，其异或和集合来源于上方dp[i-1][j]和左方dp[i][j-1]的集合，将这两个集合中的每个值与当前格子值grid[i][j]进行异或，加入当前集合。最终返回dp[m-1][n-1]中的最小值。代码框架（Python）：
def minimumXORPath(grid):
    m, n = len(grid), len(grid[0])
    dp = [[set() for _ in range(n)] for _ in range(m)]
    dp[0][0].add(grid[0][0])
    for i in range(m):
        for j in range(n):
            if i > 0:
                for val in dp[i-1][j]:
                    dp[i][j].add(val ^ grid[i][j])
            if j > 0:
                for val in dp[i][j-1]:
                    dp[i][j].add(val ^ grid[i][j])
    return min(dp[m-1][n-1])
