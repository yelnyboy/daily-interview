# 构造只有一条路径的网格

**日期**: 2026-10-27 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 初级 | **来源**: LeetCode

## 解答

思路：构造蛇形路径确保从起点到终点只有一条路径。偶数行全部开放，奇数行只开放一个连接列，连接列在左右两侧交替形成蛇形走向。这样每个分叉点只有一个有效方向，确保路径唯一。最后需确保终点可达。

代码框架（Python）：
```python
from typing import List

def createGrid(m: int, n: int) -> List[List[int]]:
    grid = [[1] * n for _ in range(m)]
    for i in range(m):
        if i % 2 == 0:
            for j in range(n):
                grid[i][j] = 0
        else:
            col = 0 if (i // 2) % 2 == 0 else n - 1
            grid[i][col] = 0
    grid[m-1][n-1] = 0
    return grid
```

常见追问：如何验证路径唯一性？可以用DFS计数所有路径数。边界情况如m=1或n=1需特判。
