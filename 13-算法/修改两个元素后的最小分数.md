# 修改两个元素后的最小分数

**日期**: 2026-11-19 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 中级 | **来源**: LeetCode

**Tags**: 贪心, 数组, 排序

## 解答

思路：题目要求修改恰好两个元素后，数组最大值与最小值之差（分数）最小。关键观察：修改的元素可以被改成数组中已有的值，因此最优策略一定是消除当前的最大值或最小值。排序后，只有四种可能：1) 把两个最大值改小（消除两个最大值）；2) 把两个最小值改大（消除两个最小值）；3) 消除一个最大值和一个最小值。排序后取 nums[n-3]-nums[0]、nums[n-1]-nums[2]、nums[n-2]-nums[1] 三者的最小值即可（n>=4 时保证至少剩两个元素）。时间复杂度 O(n log n)，空间 O(1)。代码框架：

def minimizeScore(nums):
    nums.sort()
    n = len(nums)
    return min(nums[n-3]-nums[0], nums[n-2]-nums[1], nums[n-1]-nums[2])

常见追问点：为什么只需考虑这三种情况？因为修改后的值可以任意选取，最优解必然让剩余元素的最大最小差最小，即去掉两端各若干个元素；能否证明修改元素改成剩余区间内的值最优？可以，因为改成区间内值不影响最大最小值。
