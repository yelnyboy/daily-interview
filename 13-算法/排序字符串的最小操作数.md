# 排序字符串的最小操作数

**日期**: 2026-10-21 | **类型**: Algorithm | **原始分类**: 算法 | **路线图模块**: 13-算法 | **难度**: 中级 | **来源**: LeetCode

**Tags**: 字符串

## 解答

思路：本题通常指通过交换相邻字符使字符串按字典序排序的最小操作数，这等价于求字符串中的逆序对数量。可以使用归并排序在O(n log n)时间内求解。在归并过程中，当右半部分元素先于左半部分元素放入临时数组时，左半部分剩余元素均与该元素构成逆序对。
代码框架（Python）：
def min_operations_to_sort(s: str) -> int:
    arr = [ord(c) for c in s]
    temp = [0] * len(arr)
    return merge_sort(arr, temp, 0, len(arr) - 1)

def merge_sort(arr, temp, left, right):
    if left >= right: return 0
    mid = (left + right) // 2
    count = merge_sort(arr, temp, left, mid) + merge_sort(arr, temp, mid + 1, right)
    i, j, k = left, mid + 1, left
    while i <= mid and j <= right:
        if arr[i] <= arr[j]:
            temp[k] = arr[i]; i += 1
        else:
            temp[k] = arr[j]; j += 1
            count += (mid - i + 1)
        k += 1
    while i <= mid: temp[k] = arr[i]; i += 1; k += 1
    while j <= right: temp[k] = arr[j]; j += 1; k += 1
    arr[left:right+1] = temp[left:right+1]
    return count
