# 数据库面试知识点

**日期**: 2026-11-12 | **类型**: Theory | **原始分类**: 数据库 | **路线图模块**: 14-编程基础 | **难度**: 中级 | **来源**: GitHub

## 解答

数据库是后端面试的核心模块，主要考点分点如下：1) 索引原理：B+ 树结构、聚簇索引与非聚簇索引的区别、为什么用 B+ 树而不是 B 树或哈希表（范围查询、磁盘 IO 次数少）、覆盖索引与回表；2) 事务 ACID：原子性（undo log）、持久性（redo log）、隔离性（锁+MVCC）、一致性；3) 事务隔离级别：读未提交、读已提交、可重复读（MySQL 默认）、串行化，以及脏读、不可重复读、幻读问题；4) MVCC 多版本并发控制：版本链、ReadView、快照读与当前读的区别；5) 锁机制：行锁、间隙锁、临键锁如何解决幻读；6) SQL 优化：explain 执行计划分析、慢查询定位、索引失效场景（函数操作、隐式类型转换、前导模糊匹配、违反最左前缀）；7) 日志系统：redo log、undo log、binlog 的作用与两阶段提交。常见追问：MySQL 的可重复读级别如何通过 MVCC 实现？什么情况下索引会失效？分库分表的策略与问题？

## 核心考点

- B+ 树索引
- 事务 ACID 与隔离级别
- MVCC 多版本并发控制
- 锁机制（间隙锁/临键锁）
- SQL 优化与执行计划
