# Python垃圾回收机制

**日期**: 2026-10-23 | **类型**: Theory | **原始分类**: Python基础 | **路线图模块**: 14-编程基础 | **难度**: 中级 | **来源**: GitHub

## 解答

1. 引用计数：Python主要使用引用计数机制，每个对象内部维护一个引用计数字段。当对象被引用时计数加1，引用解除时减1。当计数降为0时，对象占用的内存会立即被回收。
2. 标记-清除：为了解决容器对象（如列表、字典等）可能产生的循环引用问题，Python引入了标记-清除算法。该算法从根对象集合出发，遍历所有可达对象并进行标记，未被标记的不可达对象将被回收。
3. 分代回收：为了提高垃圾回收效率，Python将对象分为三代（第0代、第1代、第2代）。新创建的对象放在第0代，经过一次垃圾回收仍存活的对象会被移到下一代。随着代数增加，垃圾回收的频率逐渐降低，因为存活时间越长的对象通常越不可能是垃圾。
4. 触发机制：当新分配的内存减去释放的内存达到特定阈值时，会触发第0代垃圾回收。第0代回收多次后触发第1代，依此类推。
常见追问点：如何手动触发垃圾回收？循环引用中的对象如何被回收？
