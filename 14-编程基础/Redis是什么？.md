# Redis是什么？

**日期**: 2026-10-17 | **类型**: Theory | **原始分类**: 中间件 | **路线图模块**: 14-编程基础 | **难度**: 初级 | **来源**: GitHub

## 解答

1. 基本定义：Redis是一个开源的、基于内存的键值对存储数据库，通常用作缓存、消息队列或分布式锁。
2. 数据结构：支持丰富的数据类型，如字符串、哈希、列表、集合、有序集合等。
3. 持久化机制：提供RDB（快照）和AOF（追加日志）两种持久化方式，保障数据安全。
4. 高可用与扩展：支持主从复制、哨兵模式实现高可用，以及Cluster模式实现分布式横向扩展。
常见追问点：Redis为什么这么快？缓存穿透、击穿、雪崩如何解决？RDB和AOF的优缺点是什么？

## 核心考点

- 内存存储
- 数据类型丰富
- 持久化机制
- 高可用架构
- 缓存应用
