# 面经：进程与线程的区别

**日期**: 2026-10-12 | **类型**: Theory | **原始分类**: 操作系统 | **路线图模块**: 14-编程基础 | **难度**: 初级 | **来源**: GitHub

## 解答

进程与线程是操作系统中并发执行的基本单元，主要区别如下：
1. 资源分配：进程是操作系统进行资源分配的基本单位，拥有独立的地址空间和系统资源；线程是CPU调度的最小单位，同一进程内的线程共享进程的内存和资源。
2. 开销大小：进程的创建、销毁和上下文切换开销较大，因为需要切换页表等地址空间；而线程由于共享资源，切换时仅需保存少量寄存器和栈指针，开销较小。
3. 通信方式：进程间通信（IPC）较为复杂，需借助管道、消息队列、共享内存等机制；线程间通信则非常方便，可直接读写共享数据，但需使用锁、信号量等同步机制防止数据竞争。
4. 健壮性：多进程程序中一个进程崩溃通常不会影响其他进程，健壮性较高；而多线程程序中一个线程崩溃可能导致整个进程崩溃。
