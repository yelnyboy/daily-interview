# Python里的拷贝

**日期**: 2026-10-26 | **类型**: Theory | **原始分类**: Python基础 | **路线图模块**: 14-编程基础 | **难度**: 初级 | **来源**: GitHub

## 解答

1. 赋值（引用传递）：在Python中，对象的赋值实际上是创建了对原对象的引用，新变量和原变量指向同一个内存地址，修改其中一个会影响另一个。2. 浅拷贝：通过copy模块的copy()方法或对象的内置方法（如list.copy()）实现。浅拷贝会创建一个新的顶层对象，但内部嵌套的子对象仍然是引用。3. 深拷贝：通过copy模块的deepcopy()方法实现。深拷贝会递归地复制对象及其所有嵌套子对象，生成一个完全独立的副本。4. 追问点：对于自定义类，如何控制其深拷贝的行为？

## 核心考点

- 赋值引用
- 浅拷贝
- 深拷贝
- copy模块
- 可变与不可变对象
