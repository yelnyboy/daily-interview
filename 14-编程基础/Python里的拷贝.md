# Python里的拷贝

**日期**: 2026-10-28 | **类型**: Theory | **原始分类**: Python基础 | **路线图模块**: 14-编程基础 | **难度**: 初级 | **来源**: GitHub

## 解答

Python中的对象拷贝主要分为赋值、浅拷贝和深拷贝三种机制。
1. 直接赋值：仅创建对象的引用，不复制实际数据。新旧对象指向同一内存地址，修改其中一个会影响另一个。
2. 浅拷贝：创建一个新对象，但新对象内部的元素仍是原对象内部元素的引用。可通过copy.copy()或切片[:]实现。对于不可变类型互不影响，但若包含可变子对象（如嵌套列表），修改子对象仍会相互影响。
3. 深拷贝：递归地复制对象及其所有子对象，生成一个完全独立的副本。通过copy.deepcopy()实现，修改新对象不会对原对象产生任何影响。
4. 不可变对象处理：对于不可变对象（如整数、字符串、元组），深浅拷贝通常会直接返回原对象的引用，因为它们无法被修改，无需额外复制。
