# Redis核心原理

**日期**: 2026-10-29 | **类型**: Theory | **原始分类**: 中间件 | **路线图模块**: 14-编程基础 | **难度**: 中级 | **来源**: GitHub

## 解答

1. 单线程与IO多路复用：Redis核心网络模型基于Reactor模式，使用epoll实现IO多路复用，单线程处理命令避免了并发冲突和线程切换开销。
2. 高效数据结构：Redis基于内存，底层采用SDS（动态字符串）、跳表、压缩列表、哈希表等优化结构，兼顾内存和性能。
3. 持久化机制：RDB通过快照定期保存内存数据，恢复快但可能丢数据；AOF记录每次写命令，数据安全性高但文件大；支持混合持久化。
4. 高可用架构：主从复制实现读写分离和数据备份；哨兵模式监控节点状态并自动故障转移；Cluster模式通过哈希槽实现数据分片，支持横向扩展。

## 核心考点

- IO多路复用
- 单线程模型
- 内存数据结构
- 持久化机制
- 高可用架构
