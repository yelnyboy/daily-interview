# 数据库核心知识点（面试理论题）

**日期**: 2026-11-16 | **类型**: Theory | **原始分类**: 数据库 | **路线图模块**: 14-编程基础 | **难度**: 中级 | **来源**: GitHub

## 解答

数据库面试通常围绕以下几个核心方向展开：
1. 索引原理：B+树是最常见的索引结构，叶子节点存数据并用链表串联，适合范围查询；聚簇索引决定数据的物理存储顺序，非聚簇索引存储主键引用需要回表操作。
2. 事务ACID：原子性通过undo log保证，持久性通过redo log保证，隔离性通过锁和MVCC实现，一致性是最终目标。
3. 隔离级别：读未提交、读已提交、可重复读（MySQL默认）、串行化，分别解决脏读、不可重复读、幻读问题；MySQL的InnoDB通过间隙锁在可重复读级别下解决幻读。
4. MVCC机制：通过版本链和ReadView实现快照读不加锁，提升并发性能。
5. 锁机制：行锁、表锁、间隙锁、Next-Key Lock的区别与使用场景。
6. SQL优化：explain分析执行计划，关注type、key、rows等字段；避免索引失效场景（如函数操作、隐式类型转换、前导模糊匹配）。
7. 主从复制与分库分表：主从延迟问题、读写分离策略、垂直/水平拆分原则。
常见追问点：为什么用B+树而不是B树或哈希表？redo log和binlog的区别？如何排查慢查询？

## 核心考点

- B+树索引原理
- 事务ACID与隔离级别
- MVCC多版本并发控制
- 锁机制（行锁/间隙锁）
- SQL优化与执行计划分析
