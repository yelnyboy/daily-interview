# Python基础知识

**日期**: 2026-10-24 | **类型**: Theory | **原始分类**: Python基础 | **路线图模块**: 14-编程基础 | **难度**: 初级 | **来源**: GitHub

## 解答

1. 数据类型：Python内置了丰富的数据类型，如列表、元组、字典、集合等，支持动态类型，使用方便。2. 面向对象：支持类、继承、多态和封装，具有丰富的魔术方法（如__init__, __str__）实现运算符重载等。3. 内存管理：采用引用计数和垃圾回收机制（GC）自动管理内存，开发者无需手动释放。4. GIL限制：全局解释器锁限制了多线程的并行执行，CPU密集型任务需使用多进程（multiprocessing）来利用多核。5. 装饰器与生成器：装饰器用于不修改原函数代码的情况下扩展功能，生成器用于惰性计算，节省内存。常见追问点：Python中深拷贝和浅拷贝的区别是什么？

- 内存管理
