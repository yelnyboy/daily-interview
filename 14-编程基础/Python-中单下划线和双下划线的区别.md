# Python 中单下划线和双下划线的区别

**日期**: 2026-11-17 | **类型**: Theory | **原始分类**: Python基础 | **路线图模块**: 14-编程基础 | **难度**: 初级 | **来源**: GitHub

## 解答

Python 中下划线约定和机制是面试高频考点，分点说明：1. 单前导下划线 _var：仅是约定，表示'内部使用/私有提示'，解释器不做强制访问限制，但 from module import * 不会导入以 _ 开头的名称。2. 单末尾下划线 var_：用于避免与 Python 关键字冲突，如 class_、list_。3. 双前导下划线 __var：触发名称修饰，类内部会将其改写为 _ClassName__var，用于避免子类中的命名冲突，实现一定程度的'私有化'，但仍可通过改写后的名字访问，并非真正的访问控制。4. 双前后下划线 __var__：Python 的魔术方法/魔法属性（如 __init__、__len__），由解释器调用，开发者不应自定义这种命名。5. 单独的下划线 _：在交互式解释器中表示上一个表达式的结果；在循环或解包中作为'丢弃变量'，如 for _ in range(10)、a, _ = (1, 2)。常见追问：__var 的名称修饰如何实现多继承下的属性隔离；为什么说 Python 没有真正的私有属性；from import * 与 __all__ 的关系。

## 核心考点

- 单下划线约定私有
- 双下划线名称修饰
- 魔术方法命名
- 丢弃变量用法
- import * 导入规则
