# 计算机网络基础知识

**日期**: 2026-11-19 | **类型**: Theory | **原始分类**: 计算机网络 | **路线图模块**: 14-编程基础 | **难度**: 初级 | **来源**: GitHub

## 解答

计算机网络是面试高频基础模块，核心知识点分点如下：1) 分层模型：OSI 七层与 TCP/IP 四层模型，各层职责（物理、数据链路、网络、传输、应用）；2) TCP 与 UDP 区别：TCP 面向连接、可靠传输、有拥塞控制和流量控制；UDP 无连接、开销小、适合实时场景；3) 三次握手与四次挥手：建立连接需三次握手保证双方收发能力确认，断开需四次挥手因半关闭特性，TIME_WAIT 状态持续 2MSL；4) HTTP/HTTPS：HTTP 无状态，HTTPS 通过 TLS 加密，涉及非对称交换密钥+对称加密传输；5) 从输入 URL 到页面显示：DNS 解析、TCP 连接、HTTP 请求、服务端响应、浏览器渲染。常见追问点：为什么握手三次不是两次；TCP 如何保证可靠传输（序号、确认、重传、滑动窗口）；HTTP 1.1/2/3 的演进（长连接、多路复用、QUIC）。

## 核心考点

- TCP/IP 分层模型
- 三次握手四次挥手
- TCP与UDP区别
- HTTPS加密原理
- DNS解析流程
