# Python中is运算符的原理与使用

**日期**: 2026-11-14 | **类型**: Theory | **原始分类**: Python基础 | **路线图模块**: 14-编程基础 | **难度**: 初级 | **来源**: GitHub

## 解答

is是Python中的身份运算符，用于判断两个变量是否引用同一个对象（即id是否相同），而==判断的是值是否相等（调用__eq__方法）。要点如下：
1. 本质区别：is比较对象身份（内存地址），==比较对象值；a is b等价于id(a) == id(b)。
2. 典型例子：a = [1,2,3]; b = [1,2,3]，则a == b为True，但a is b为False，因为是两个不同的列表对象。
3. 小整数缓存：CPython中[-5, 256]范围内的整数会被缓存复用，因此a=256, b=256时a is b为True，但a=257, b=257时可能为False（在交互式环境中），这是实现细节，不应依赖。
4. 字符串驻留（interning）：编译期确定的短字符串可能被驻留共享，但同样是实现细节，不能作为编程依据。
5. 正确使用场景：is应该只用于与单例对象比较，如 x is None、x is True/False，这也是PEP 8推荐的风格，因为None是全局单例，用is比==更安全高效（避免__eq__被重载的副作用）。
6. 性能：is是简单的指针比较，比==更快，但这不是滥用is的理由。

常见追问：为什么判断None要用is而不用==？is和==在自定义类中如何重载（==可重载__eq__，is不可重载）？

## 核心考点

- 身份比较vs值比较
- id()函数
- 小整数缓存
- 字符串驻留
- None判断用is
