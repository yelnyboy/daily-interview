# 分布式系统面试连环炮

**日期**: 2026-10-21 | **类型**: Theory | **原始分类**: 分布式 | **路线图模块**: 02-LLM核心与提示工程 | **难度**: 高级 | **来源**: GitHub

## 解答

分布式系统面试连环炮通常涵盖以下几个核心连环考点：
1. CAP与BASE理论：分布式系统在一致性、可用性、分区容错性间权衡，通常P必选。BASE理论提倡最终一致性，是高可用系统的实践准则。
2. 分布式锁：常考Redis与Zookeeper实现差异。Redis依赖过期时间和Lua脚本保证原子性（如Redlock），ZK基于临时顺序节点和Watch机制，具有天然防死锁特性。
3. 分布式事务：从强一致性的2PC、3PC，到柔性事务的TCC（Try-Confirm-Cancel），再到基于本地消息表或MQ的最终一致性方案，需结合业务场景选择。
4. 数据分片与负载均衡：一致性哈希算法解决节点动态增减时的数据迁移问题，常配合虚拟节点解决数据倾斜。
5. 幂等性设计：防止接口重复调用导致数据脏写，常用Token机制、数据库唯一索引或状态机校验。
常见追问：在超高并发场景下，如何设计一个兼顾高可用与数据一致性的分布式锁服务？
