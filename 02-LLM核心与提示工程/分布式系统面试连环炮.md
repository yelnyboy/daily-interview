# 分布式系统面试连环炮

**日期**: 2026-11-21 | **类型**: Theory | **原始分类**: 分布式 | **路线图模块**: 02-LLM核心与提示工程 | **难度**: 高级 | **来源**: GitHub

## 解答

分布式系统面试常以连环炮形式考察知识体系，核心考点如下：

1. CAP理论：分布式系统在一致性（C）、可用性（A）、分区容错性（P）三者中最多同时满足两个；网络分区不可避免，实际是CP与AP的取舍。
2. BASE理论：基本可用、软状态、最终一致性，是AP系统的实践准则，与ACID相对。
3. 分布式事务：2PC（强一致但阻塞、协调者单点）、3PC、TCC（Try-Confirm-Cancel）、Saga（长事务拆分+补偿）、本地消息表、基于MQ的最终一致性方案。
4. 分布式锁：Redis的SETNX+过期时间（需处理续期与误删，如Redisson看门狗）、RedLock争议、ZooKeeper临时顺序节点方案。
5. 一致性算法：Paxos（理论复杂）、Raft（Leader选举、日志复制、安全性，工程上更流行）。
6. 分布式ID：UUID、雪花算法（Snowflake，时钟回拨问题）、号段模式。
7. 数据分片与一致性哈希：解决水平扩展与热点问题，虚拟节点解决数据倾斜。
8. 幂等性设计：唯一请求号、去重表、状态机，防止重试导致重复操作。

常见追问点：Raft选举过程与脑裂处理；雪花算法时钟回拨怎么办；Redis分布式锁主从切换导致锁丢失如何解决；如何保证消息不丢不重。

## 核心考点

- CAP与BASE理论
- 分布式事务方案
- Raft一致性算法
- 分布式锁实现
- 幂等性设计
