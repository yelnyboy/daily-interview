# 分布式系统面试连环炮

**日期**: 2026-11-10 | **类型**: Theory | **原始分类**: 分布式 | **路线图模块**: 02-LLM核心与提示工程 | **难度**: 高级 | **来源**: GitHub

## 解答

分布式系统面试连环炮通常按知识链层层深入，核心考点如下。1）CAP理论：分布式系统在一致性、可用性、分区容错性中最多同时满足两个，网络分区不可避免，实际是在CP与AP间权衡。2）BASE理论：基本可用、软状态、最终一致，是AP系统的实践指导。3）分布式事务：两阶段提交（2PC）强一致但阻塞且协调者单点；三阶段提交减少阻塞；TCC（Try-Confirm-Cancel）业务补偿；Saga模式拆分长事务为本地事务+补偿；本地消息表/事务消息保证最终一致。4）一致性协议：Paxos复杂难实现，Raft通过领导者选举、日志复制、安全性约束实现共识，是工程主流（如etcd）。5）分布式锁：Redis的SETNX+过期时间+续期（Redisson看门狗），或ZooKeeper临时顺序节点，需注意锁过期与误删问题。6）幂等设计：唯一请求ID+去重表、数据库唯一约束、乐观锁版本号。7）高可用：主从复制、哨兵、集群分片、限流熔断降级。常见追问：Raft选举流程？如何解决Redis主从切换导致的锁丢失？

## 核心考点

- CAP与BASE理论
- 分布式事务（2PC/TCC/Saga）
- Raft/Paxos共识协议
- 分布式锁与幂等性
- 高可用与数据复制
