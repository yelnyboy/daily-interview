# 分布式系统面试连环炮

**日期**: 2026-10-19 | **类型**: Theory | **原始分类**: 分布式 | **路线图模块**: 02-LLM核心与提示工程 | **难度**: 中级 | **来源**: GitHub

## 解答

分布式系统面试通常围绕以下核心概念展开连环追问：

1. CAP理论：分布式系统在一致性、可用性、分区容错性三者中只能满足两个，网络分区不可避免，需在CP和AP间权衡。
2. 一致性算法：Raft通过领导者选举和日志复制实现强一致性，比Paxos更易理解和实现，是工业界主流选择。
3. 分布式锁：基于Redis的SETNX或RedLock算法适合高并发场景，基于Zookeeper临时顺序节点适合强一致性场景，需考虑锁过期、可重入和羊群效应。
4. 分布式事务：2PC保证强一致性但阻塞且存在单点故障，3PC减少阻塞，Saga模式通过补偿事务实现最终一致性，适用于微服务场景。
5. 幂等性设计：通过唯一ID、Token机制或数据库唯一约束防止重复操作，保证接口重复调用结果一致。

常见追问点：分布式ID生成方案对比？如何保证消息队列顺序性？分布式系统如何做限流？

## 核心考点

- CAP理论
- Raft一致性算法
- 分布式锁
- 分布式事务
- 幂等性设计
