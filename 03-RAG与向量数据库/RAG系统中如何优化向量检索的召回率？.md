# RAG系统中如何优化向量检索的召回率？

**日期**: 2026-10-12 | **类型**: Theory | **原始分类**: RAG与向量数据库 | **路线图模块**: 03-RAG与向量数据库 | **难度**: 中级 | **来源**: GitHub

## 解答

优化RAG系统的向量检索召回率需从数据、模型和检索策略多维度入手。首先在数据层面，应提升文档分块质量，采用基于语义的分块策略而非固定长度，以保留上下文完整性。其次在模型层面，选择或微调更适合特定业务领域的Embedding模型，以提升语义表征的准确性。在检索策略上，引入混合检索机制，结合稠密向量检索与基于关键词的稀疏向量检索（如BM25），以捕获不同维度的语义匹配。最后，通过引入重排序模型对初步召回的文档进行二次打分过滤，虽不直接提升召回率，但能确保高相关性内容被优先提供给LLM。常见追问点在于如何评估和平衡检索的召回率与精确率。

## 核心考点

- 语义分块
- Embedding模型
- 混合检索
- 稀疏向量
- 重排序模型
