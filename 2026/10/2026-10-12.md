## 1. 对数组执行操作以最大化平方和

**Type**: Algorithm | **Category**: 算法 | **Difficulty**: 高级 | **Source**: LeetCode

**Tags**: 贪心, 位运算, 数组, 哈希表

### 解答

思路：题目允许对数组中任意两个元素执行任意次操作：`a, b = a & b, a | b`。观察发现，对于任意一个二进制位，操作前后该位上1的总数保持不变。因此，该操作的本质是允许我们将数组中所有1的二进制位重新分配到任意位置。为了使选取的k个元素的平方和最大，由于平方函数是凸函数，应尽量让某些元素的值尽可能大。因此采用贪心策略：统计所有元素在每个二进制位上1的总数，然后从最高位到最低位构建k个元素，每次将剩余的1尽可能分配给当前构建的元素。代码框架(Python)：
```python
def maxSum(nums, k):
    cnt = [0] * 31
    for x in nums:
        for i in range(31):
            if (x >> i) & 1:
                cnt[i] += 1
    ans = 0
    mod = 10**9 + 7
    for _ in range(k):
        cur = 0
        for i in range(31):
            if cnt[i] > 0:
                cnt[i] -= 1
                cur |= (1 << i)
        ans = (ans + cur * cur) % mod
    return ans
```
常见追问点：如何证明该贪心策略的正确性？如果要求最小化平方和该怎么做？

### 核心考点

- 位运算性质
- 贪心策略
- 二进制位重新分配
- 凸函数极值

### 常见追问

> 为什么这种操作等价于自由分配二进制位上的1的数量？

## 2. Python中的作用域

**Type**: Theory | **Category**: Python基础 | **Difficulty**: 初级 | **Source**: GitHub

### 解答

Python中的作用域决定了变量的可见性和生命周期，遵循LEGB查找规则：
1. L(Local)：局部作用域，函数内部定义的变量，仅在函数运行时存在。
2. E(Enclosing)：嵌套作用域，外层函数中的变量，常用于闭包机制。
3. G(Global)：全局作用域，模块级别定义的变量，整个模块内均可访问。
4. B(Built-in)：内置作用域，Python预定义的变量或函数（如print, len）。
当在函数内部修改全局变量时，必须使用global关键字声明；若要在嵌套函数中修改外层非全局变量，则需使用nonlocal关键字。若未声明直接修改，Python会将其视为局部变量并在赋值时报错。
常见追问点：global和nonlocal的区别是什么？闭包是如何利用作用域的？

### 核心考点

- LEGB规则
- 局部作用域
- global关键字
- nonlocal关键字
- 闭包

### 常见追问

> global和nonlocal关键字在使用上有什么具体区别？

## 3. 面经：Redis缓存穿透、击穿、雪崩的区别及解决方案

**Type**: Theory | **Category**: 数据库 | **Difficulty**: 中级 | **Source**: GitHub

### 解答

这三者都是高并发下缓存失效导致数据库压力骤增的典型问题：
1. 缓存穿透：查询一个缓存和数据库都不存在的数据，每次请求都直达数据库。解决方案：缓存空值并设置短过期时间，或使用布隆过滤器拦截非法请求。
2. 缓存击穿：某个热点Key突然过期，大量并发请求同时访问该Key，瞬间压垮数据库。解决方案：加互斥锁（只允许一个线程查库并回写缓存），或热点数据逻辑永不过期。
3. 缓存雪崩：大量Key在同一时间集中过期，或Redis节点宕机，导致请求全部转发到数据库。解决方案：给过期时间加上随机值避免集中失效，搭建高可用集群防宕机，或使用多级缓存。
常见追问点：布隆过滤器的原理是什么？互斥锁在分布式环境下如何实现？

### 核心考点

- 缓存穿透
- 缓存击穿
- 缓存雪崩
- 布隆过滤器
- 互斥锁

### 常见追问
